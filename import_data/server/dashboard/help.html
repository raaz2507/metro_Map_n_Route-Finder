4-Stage Greedy Data Pipeline Architecture

Zero Data Loss & Guaranteed Schema Integrity

Our system enforces a strict 4-tier greedy pipeline to ensure no authentic data from official sources (DMRC, NMRC, NCRTC, etc.) is lost.

🔴 STAGE 1: RAW GREEDY SCRAPING (*_raw.json)
   100% authentic raw data captured without any truncation.
↓
🟡 STAGE 2: BASIC CLEANED (*_cleaned.json)
   Whitespace, syntax & duplicate cleanup. 0% structural mutation.
↓
🟢 STAGE 3: MASTER STRUCTURED (*_master.json)
   Final canonical schema verified strictly under developer supervision.
↓
❄️ STAGE 4: PRODUCTION CORE (data.json) [FROZEN]
   100% frozen, protected and client-ready.

Delta Staging Review Mechanism (Cleaned vs Master)

Automatic detection of newly commissioned stations

Delta Difference (New Staging) = Cleaned Keys − Master Keys

Dashboard Section 1 calculates this difference at runtime. Newly detected stations appear as Cyan cards for audit review.
