# 🎨 यूनिवर्सल सीएसएस डिज़ाइन सिस्टम और क्लीन कोड प्रॉम्प्ट (Universal CSS Standard)

यह प्रॉम्प्ट फ़ाइल हमारे पूरे प्रोजेक्ट के लिए **Single Source of Truth (SSOT)** है। जब भी कोई नया CSS कोड लिखा जाए या पुराना सुधारा जाए, तो इन नियमों का 100% पालन अनिवार्य है।

---

## 🚫 1. शून्य हार्डकोडिंग नियम (Zero-Magic-Number Standard)
1. **फ़ॉन्ट साइज़ में पिक्सल वर्जित**: कभी भी किसी क्लास में `11px`, `10px`, `12px`, `9px` जैसे कच्चे पिक्सल मत लिखो।
2. **कच्चे कलर्स वर्जित**: कभी भी `#000000`, `#ffffff` या `rgba(...)` कॉम्पोनेन्ट में हार्डकोड मत करो। हमेशा `base.css` के वैरिएबल्स (`var(--card-bg)`, `var(--text-primary)`, `var(--border-color)`, `var(--accent-*)`) का उपयोग करो ताकि चारों थीम्स (Dark, Light, Spa, B/W) में डिज़ाइन 100% सही दिखे।
3. **बॉर्डर विड्थ (Border Widths)**: `1px solid` या `2px solid` की जगह हमेशा टोकन्स का उपयोग करो:
   - `border: var(--border-thin) solid var(--border-color);` (1px)
   - `border-bottom: var(--border-thick) solid var(--accent-amber);` (2px)
4. **लाइन हाइट्स (Line Heights)**: `line-height: 1.6` जैसे कच्चे नंबर्स के बजाय टोकन्स:
   - `line-height: var(--leading-relaxed);` (1.6)
   - `line-height: var(--leading-normal);` (1.5)
5. **शैडोज़ (Shadows)**: कच्चे `box-shadow: inset ... rgba(...)` के बजाय:
   - `box-shadow: var(--shadow-inset);` या `var(--shadow-md);`
6. **मोनोस्पेस गटर (Gutter Line Numbers)**: `44px` जैसे मैजिक पिक्सल के बजाय शुद्ध टाइपोग्राफी यूनिट **`ch` (Character Width)** का उपयोग करो:
   - `width: 4.5ch; min-width: 4.5ch;` (फ़ॉन्ट साइज़ बदलने पर लाइन नंबर अपने आप स्केल होते हैं)।
7. **फ़्लेक्स और इनपुट विड्थ**: `180px` जैसे मैजिक नंबर्स के बजाय रूट-रिलेटिव `rem`:
   - `flex: 1; min-width: 12rem;`
8. **फ़ॉन्ट फ़ैमिली**: `'Share Tech Mono', monospace` बार-बार टाइप करने के बजाय हमेशा `var(--font-mono)` का इस्तेमाल करो।

## 📐 2. मिनिमलिस्ट 3-लेवल टाइपोग्राफी (No Over-Engineering)
30 अलग-अलग वेरिएबल्स (`--fs-3xs`, `--fs-2xs` आदि) का जंगल पूरी तरह समाप्त। हमारी पूरी साइट केवल **3 स्तरों (3 Levels)** पर चलेगी:

```css
:root {
	--text-sm:   0.8rem;   /* छोटा टेक्स्ट: बैज (Badges), लाइन नंबर, सबटेक्स्ट, चिप्स */
	--text-base: 1rem;     /* सामान्य टेक्स्ट: टेबल सेल्स, बटन्स, इनपुट्स, बॉडी */
	--text-lg:   1.25rem;  /* बड़े टाइटल्स: हेडिंग्स, मॉडल हेडर्स, कार्ड टाइटल्स */

	/* बॉर्डर्स, लीडिंग और एलिवेशन टोकन्स */
	--border-thin: 1px;
	--border-thick: 2px;
	--leading-normal: 1.5;
	--leading-relaxed: 1.6;
	--shadow-inset: inset 0 2px 4px rgba(0, 0, 0, 0.2);
}

html {
	font-size: var(--base-font-size, 14px); /* हेडर का स्लाइडर इसे 12px से 22px लाइव कंट्रोल करता है */
}
```

*नोट*: 90% सामान्य HTML एलिमेंट्स अपने आप रूट फ़ॉन्ट साइज़ इनहेरिट (Inherit) करते हैं, इसलिए हर जगह `font-size` बार-बार लिखने की ज़रूरत नहीं है।

## 🧹 3. पुरानी और फ़ालतू सीएसएस हटाना (Dead & Duplicate CSS Purge)
1. **डुप्लीकेट क्लासेस तुरंत डिलीट करो**: एक ही क्लास को दो फाइलों में अलग-अलग मत लिखो (जैसे `.stage-view-tab` या `.viewport-header` को दोबारा डिफाइन करना मना है)।
2. **अनयूज्ड कोड हटाओ**: जो स्टाइल्स अब इस्तेमाल नहीं हो रहीं, उन्हें तुरंत साफ़ करो।
3. **कॉम्पैक्ट और साफ़ स्ट्रक्चर**: 15 अलग-अलग छोटी-छोटी फाइलों में बिखरने के बजाय कॉमन स्टाइल्स को एक जगह समेट कर रखो।

---

## 📱 4. बिना ओवर-इंजीनियरिंग के रिस्पॉन्सिव (Fluid Layouts)
1. **बिना मीडिया क्वेरी के ग्रिड**:
   ```css
   grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
   gap: var(--space-md);
   ```
2. **फ्लूइड स्पेसिंग**: पैडिंग और मार्जिन के लिए केवल `base.css` के स्पेसिंग टोकन्स (`var(--space-xs)`, `var(--space-sm)`, `var(--space-md)`, `var(--space-lg)`) का प्रयोग करो।
